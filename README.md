# TestComplete OpenCart Automation Framework

## Project Overview
A QA automation portfolio project demonstrating UI test automation using SmartBear TestComplete, JavaScript, keyword-driven testing, and reusable object identification.

## Automation Coverage
- User registration
- Login and logout
- Web application navigation
- Keyword-driven UI testing
- Object identification using Name Mapping

## Technology Stack
- SmartBear TestComplete 15
- JavaScript
- Keyword-Driven Testing
- Git and GitHub
- Jenkins (CI integration planned)

## Project Structure
Frameworks/ProjectSuiteTestFramework/
- TF1/Script - JavaScript automation scripts
- TF1/KeywordTests - Keyword-driven tests
- TF1/NameMapping - Centralized object identification

## CI/CD
Jenkins integration is planned for automated repository validation and reporting.

TestComplete UI execution requires a valid TestComplete or TestExecute license and an appropriate Windows execution environment.

## Security
Credentials and sensitive test data are excluded from the published framework.
